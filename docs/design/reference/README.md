# Capturas derivadas del prototipo v1.0
Generadas en Chromium desde el HTML original, con datos iniciales de ejemplo. 01–22: escritorio 1280×900 tema claro; 23–25: móvil 390×844 tema oscuro. Capturas de página completa, incluidas áreas desplazables. Se abrieron vistas de referencia mediante funciones internas del prototipo; no es una prueba de cada botón ni una validación en HAOS. Las 25 capturas se generaron sin errores de página en la ejecución final. La aprobación del propietario fue preliminar del HTML, no individual de estas imágenes. No modificar estas referencias al implementar sin documentar cambios y aprobación.
