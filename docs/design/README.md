# Referencia oficial propuesta para C.2
**Objetivo:** crear una integración que facilite usar las tiras LED inteligentes, no una integración que requiera estudiar cómo programar automatizaciones para poder utilizarlas.

Orden de referencia: políticas vigentes de AGENTS.md y seguridad del backend > decisiones aprobadas y requisitos de UX > prototipo HTML v1.0 > capturas generadas. Si discrepan, documentar el conflicto y solicitar decisión; no improvisar. El HTML es una maqueta autónoma con datos ficticios en memoria. No copiar su almacenamiento, lógica de simulación ni DOM como arquitectura de producción. La interfaz de HA usará su estado autenticado y backend real.
